# Home Bills: concept prototype

Clickable prototype for the Paytm product case (Case 2: Recharge Engagement). It walks through 14 steps of a single-bill user becoming a household bill payer on Paytm.

- Open `index.html` (or the GitHub Pages link) in a desktop browser.
- Use **Next / Back** in the side panel, or switch to **Explore freely** and tap the phone.
- All data is synthetic. The prototype is a concept and is not affiliated with Paytm.
